# netKathir Bot - React + TypeScript Chatbot UI

Modern chatbot interface with React 18, TypeScript, Tailwind CSS, and Zustand.

## Quick Start

```bash
npm install
npm run dev
```

## Features

- 🎨 ChatGPT/Claude-style UI
- 📱 Fully responsive
- 🌙 Dark mode
- 💬 Thread management
- ✏️ Editable titles
- ⚡ Auto-scroll
- ⌨️ Keyboard shortcuts

## Tech Stack

- React 18 + TypeScript
- Tailwind CSS
- Zustand (state)
- Lucide React (icons)
- Vite (build)

Open http://localhost:5173 after running `npm run dev`
